Daily - an addon for the Sonix Player (TempoTec V3 Analog)
Трек дня - аддон для Sonix Player (TempoTec V3 Analog)

INSTALL / УСТАНОВКА
  These files belong in <card>/Addons/daily/ - addon.json has to sit directly
  in that folder. The tile appears under More when the card is read.
  Эти файлы кладутся в <card>/Addons/daily/ - addon.json прямо в этой папке.
  Плитка появляется в More, когда карта прочитана.

WHAT IT IS / ЧТО ЭТО
  Each day the app picks one track from your library. The same day always
  shows the same track; tomorrow it will be another. It prefers something
  you have not listened to recently, so the choice stays fresh. Tap Play to
  start it in the player.
  Каждый день приложение выбирает один трек из вашей библиотеки. В течение
  дня трек не меняется; завтра будет другой. Предпочитается то, что вы давно
  не слушали, чтобы выбор не повторялся. «Слушать» запускает трек в плеере.
