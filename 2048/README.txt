2048 - an addon for the Sonix Player (TempoTec V3 Analog)
2048 - аддон для Sonix Player (TempoTec V3 Analog)

INSTALL / УСТАНОВКА
  These files belong in <card>/Addons/2048/ - addon.json has to sit directly in
  that folder, not a level deeper. The tile appears in More when the card is
  read; a restart is normally not needed.
  Эти файлы кладутся в <card>/Addons/2048/ - addon.json должен лежать прямо в
  этой папке, не уровнем глубже. Плитка появляется в More, когда карта
  прочитана; перезапуск обычно не нужен.

WHAT IT IS / ЧТО ЭТО
  The classic 4x4 tile game: swipe to slide and merge equal numbers, reach the
  2048 tile, then keep going if you want. Tiles animate as they move and when
  a new one appears. Only the best score is kept on the card; a new visit is a
  new board.
  Классическая игра 4x4: свайп сдвигает и сливает одинаковые числа, цель -
  плитка 2048, после победы можно продолжить. Плитки анимируются при ходе и
  появлении новой. На карте хранится только лучший счёт; новый заход - новая
  партия.

CONTROLS / УПРАВЛЕНИЕ
  Swipe on the board to move. The start / win / game-over card is tapped to
  continue.
  Свайп по полю - ход. Карточка старта / победы / конца игры закрывается
  нажатием.

LANGUAGE / ЯЗЫК
  Overlay text follows the player's language (English / Russian). The tile
  title is "2048" in both.
  Текст карточек следует языку плеера (English / Russian). Заголовок плитки
  в обоих случаях - "2048".

SETTINGS / НАСТРОЙКИ
  Best score is written to settings.ini next to the addon on the card. Nothing
  else is stored, and nothing needs a network.
  Лучший счёт пишется в settings.ini рядом с аддоном на карте. Больше ничего
  не хранится, сеть не нужна.
