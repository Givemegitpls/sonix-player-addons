Gearboy - an addon for the Sonix Player (TempoTec V3 Analog)
Gearboy - аддон для Sonix Player (TempoTec V3 Analog)

INSTALL / УСТАНОВКА
  These files belong in <card>/Addons/gearboy/ - addon.json has to sit directly
  in that folder, not a level deeper. The tile appears in More when the card is
  read; a restart is normally not needed.
  Эти файлы кладутся в <card>/Addons/gearboy/ - addon.json должен лежать прямо в
  этой папке, не уровнем глубже. Плитка появляется в More, когда карта
  прочитана; перезапуск обычно не нужен.

ROMS / ROM'Ы
  Games/GB     .gb ROMs        / ROM'ы .gb
  Games/GBC    .gbc ROMs       / ROM'ы .gbc
  Games/Saves  .sav and .state1, written by the emulator
               / .sav и .state1, пишет эмулятор
  Games/Bios   optional dmg_boot.bin, cgb_boot.bin
               / необязательные dmg_boot.bin, cgb_boot.bin
  The list is rebuilt every time it is opened, so new ROMs need no restart.
  Список пересобирается при каждом открытии, новые ROM'ы видны без перезапуска.

SETTINGS / НАСТРОЙКИ
  Addons/gearboy/settings.ini - palette, shader, colour correction, boot ROM,
  changed on the emulator's settings screen.
  Addons/gearboy/settings.ini - палитра, шейдер, коррекция цвета, boot ROM;
  меняются на экране настроек эмулятора.
