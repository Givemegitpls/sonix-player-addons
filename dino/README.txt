Dino - an addon for the Sonix Player (TempoTec V3 Analog)
Dino (Динозаврик) - аддон для Sonix Player (TempoTec V3 Analog)

INSTALL / УСТАНОВКА
  These files belong in <card>/Addons/dino/ - addon.json has to sit directly in
  that folder, not a level deeper. The tile appears in More when the card is
  read; a restart is normally not needed.
  Эти файлы кладутся в <card>/Addons/dino/ - addon.json должен лежать прямо в
  этой папке, не уровнем глубже. Плитка появляется в More, когда карта
  прочитана; перезапуск обычно не нужен.

NOTHING TO SET UP / НАСТРАИВАТЬ НЕЧЕГО
  A tap jumps, a finger held down ducks. The best score is kept in
  Addons/dino/settings.ini. A run leaves the music playing.
  Касание - прыжок, удержание пальца - присесть. Лучший результат хранится в
  Addons/dino/settings.ini. Игра не трогает звук: музыка продолжает играть.
