Calculator - an addon for the Sonix Player (TempoTec V3 Analog)
Калькулятор - аддон для Sonix Player (TempoTec V3 Analog)

INSTALL / УСТАНОВКА
  These files belong in <card>/Addons/calc/ - addon.json has to sit directly in
  that folder, not a level deeper. The tile appears in More when the card is
  read; a restart is normally not needed.
  Эти файлы кладутся в <card>/Addons/calc/ - addon.json должен лежать прямо в
  этой папке, не уровнем глубже. Плитка появляется в More, когда карта
  прочитана; перезапуск обычно не нужен.

WHAT IT IS / ЧТО ЭТО
  A four-function calculator: +, -, x, /, percent, sign change, and equals.
  The top line shows the expression being built; the large line is the current
  number. Nothing is written to the card and nothing needs a network.
  Четырёхоперационный калькулятор: +, -, x, /, процент, смена знака и равно.
  Верхняя строка показывает набираемое выражение; крупная - текущее число.
  На карту ничего не пишется, сеть не нужна.

KEYS / КЛАВИШИ
  AC / C   all clear, or clear the current entry (the label switches)
  <-       delete the last digit
  %        percent (with +/− pending: n% of the left value, else /100)
  +/-      change sign
  =        equals; press again to repeat the last operation
  AC / C   полный сброс или сброс текущего ввода (подпись меняется)
  <-       удалить последнюю цифру
  %        процент (при +/−: n% от левого числа, иначе /100)
  +/-      сменить знак
  =        равно; повторное нажатие повторяет последнюю операцию

LANGUAGE / ЯЗЫК
  The tile title and the error line follow the player's language (English /
  Russian). With Russian selected the decimal separator is a comma.
  Заголовок плитки и строка ошибки следуют языку плеера (English / Russian).
  При русском языке десятичный разделитель - запятая.

NOTHING TO SET UP / НАСТРАИВАТЬ НЕЧЕГО
  No files on the card, no network, no account.
  Ни файлов на карте, ни сети, ни аккаунта.
